# 🚌 Sistema de Gestão de Transporte Escolar API

API robusta desenvolvida com **FastAPI** para gerenciar a presença de alunos e otimizar rotas diárias de transporte escolar.

## 🚀 Tecnologias
- Python 3.9+
- FastAPI
- PostgreSQL
- Pydantic (Validação de dados)

## 🛠️ Como rodar o projeto
1. Clone o repositório.
2. Instale as dependências: `pip install -r requirements.txt`
3. Configure suas variáveis de ambiente no `.env`.
4. Inicie o servidor: `uvicorn app.main:app --reload`
5. Acesse a documentação em: `http://localhost:8000/docs`
